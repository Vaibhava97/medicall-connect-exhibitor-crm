# Medicall Static Bootstrap Site

Clean, framework-free multi-page Medicall discovery site built with:

- Plain HTML
- Bootstrap 5
- Custom CSS
- Vanilla JavaScript

Pages are split into individual files such as `index.html`, `search.html`, `product.html`, `vendor.html`, `compare.html`, `profile.html`, `exhibitor.html`, `knowledge-hub.html`, `article.html`, `about.html`, and `faq.html`.

Open `index.html` directly or serve the folder with any static web server.
